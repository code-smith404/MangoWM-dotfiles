# MangoWM Multi-Theme Dotfiles (Wayland)

Online install:
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/code-smith404/MangoWM-dotfiles/multi-theme-installer/install.sh)"
```

Themes: Catppuccin Mocha, Dracula, Nord, Gruvbox Dark, Tokyo Night, Rose Pine.
Switch: `mango-theme set <name>`.
Uninstall: `./uninstall.sh`.
